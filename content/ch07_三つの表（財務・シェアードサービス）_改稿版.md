# 三つの表（改稿版）

## 第一章　三つの表

「ライズを買う」

　七月の経営会議で、大河内はそう言った。

　ライズ・フットウェアは、トレイルシューズIII を作っているメーカーで、長野に工場がある。創業者が七十歳で後継ぎがおらず、ヤマビコに声をかけてきた。

「それと、倉庫を別会社にする。ヤマビコロジ。佐藤を社長にする。丸嘉の物流も請け負えるようにしたい」

　佐藤が、会議室の隅で顔を上げた。

「社長になったら、請求書は」

「何の請求書だ」

「……いえ」

　佐藤は、それ以上言わなかった。佐藤の請求書問題は、まだ解決していなかった。

　梨乃は、経営企画室長になって三か月だった。前の室長が退職し、大河内が「梨乃でいい」と言った。名刺は変わったが、経営企画室は相変わらず二人だった。

「買収の資金は」

　橘が聞いた。

「銀行から借りる。三億。三友銀行が、来週、財務諸表を持ってこいと言ってる。三年分」

　橘は頷いた。眼鏡は、まだ上がっていなかった。

「用意します。ただ、社長、三億借りると、ヤマビコの自己資本比率が下がります。銀行は、それを見ます」

「自己資本比率」

　梨乃は、その言葉の意味を、正確には知らなかった。

「借金ってのはな」

　社長が言った。梨乃は身構えた。

「傘だ。傘は……雨の日に差す」

「はい」

「銀行は、晴れの日に傘を貸す」

　会議室が静かになった。橘が、眼鏡を押し上げた。満足のほうだった。

「それは、昔からある言葉です」

「知ってる。だから当たってる」

　社長は、当たる例えの半分が、自分のものではないことを自覚していた。梨乃はそれを初めて聞いた。

---

　会議のあと、梨乃は橘の席に行った。

　経理部は四人。橘と、パートの二人と、四月に入った新卒の一人。橘の机の上には、電卓と、眼鏡拭きと、なぜか資金繰り表が三枚あった。まだ誰にも頼まれていない資金繰り表だった。

「橘さん、財務諸表というのは、何枚あるんですか」

「三枚です。損益計算書、貸借対照表、キャッシュフロー計算書。PL、BS、CF。三つの表」

「三つ」

「三つです。三つの売上、三人の佐藤花子、三つの表。この会社は、三つが好きですね」

　橘が、珍しく冗談を言った。梨乃は、それを議事録に書きたかったが、議事録はなかった。

「梨乃さんは、三年前、『三つの売上』を一つにしましたよね。あのとき決めた計上売上が、この一枚目の、一番上の行です」

```
損益計算書（PL）　前期
  売上高               4,180
  売上原価             2,340
  売上総利益（粗利）     1,840     ← 二つ目の話で出した「カテゴリ別粗利」の合計
  販売費及び一般管理費   1,510     ← 人件費、広告費、倉庫の家賃、AWS の請求書
  営業利益              330
  営業外損益            △12       ← 借入の利息
  経常利益              318
  法人税等              96
  当期純利益            222
                                （単位：百万円）
```

「PL は、一年間で、いくら売って、いくら使って、いくら残ったか。上から下へ引き算するだけです。これは、たぶん梨乃さんにもわかる」

「わかります。営業利益が三億三千万」

「では二枚目」

```
貸借対照表（BS）　前期末
  資産                          負債
    現金預金         410            買掛金         290   ← ライズなどへの未払い
    売掛金           620            未払金・未払費用 85
    商品（在庫）      780            短期借入金      150
    その他流動        45             長期借入金      400
    固定資産（設備等） 180            負債合計        925
    ソフトウェア等     95
                                  純資産
                                    資本金          50
                                    利益剰余金     1,155  ← 創業以来の純利益の積み上げ
                                    純資産合計     1,205
  資産合計          2,130           負債・純資産合計 2,130
```

「BS は、『ある一日の終わりに、何を持ってて、それは誰のものか』です。左が、持ってるもの。右が、それを誰から調達したか。右の上半分は、いつか返さないといけない他人のお金。下半分は、返さなくていい自分のお金」

「左と右が同じ数字」

「同じになります。持ってるものは、必ず誰かのお金で買ったからです」

　そこへ三上が来た。経理部に三上が来るのは珍しかった。

「梨乃、経営会議の資料、どこにある」

「今、財務諸表の勉強中です」

「財務諸表」

　三上は BS を覗き込んだ。

「売掛金ってなんだ」

「まだもらってないお金です。売ったけど、入金はこれからのもの」

「買掛金は」

「まだ払ってないお金です。仕入れたけど、支払いはこれからのもの」

「じゃあ、俺のテントは、ヤマビコの買掛金か」

「部長のテントは、部長がカードで買ってるので、ヤマビコの売掛金です。決済代行から五日で入金されるので、すぐ現金になります」

「俺は、ヤマビコの資産か」

「部長の購入は、資産になります。部長ご自身は、人件費です」

「……そうか」

　三上は、少し考えて、「わかった！」と言って出ていった。経営会議の資料は、探さなかった。

「純資産千二百五を、資産二千百三十で割ると、五十六パーセント。これが自己資本比率。三億借りると、右の上に三百が増えて、左の現金に三百が増えます。資産二千四百三十、純資産は変わらず千二百五、比率は四十九パーセントに下がる」

　梨乃は、表を見つめた。

「在庫が七百八十。現金より多い」

「多いです。志村さんが商品を正本にしたとき、初めて在庫の金額が正確に出るようになりました。それまでは、倉庫システムの数に仕入単価を掛けた概算でした。正確になったら、思ったより多かった」

「在庫は、資産なんですね」

「資産です。売れば現金になるので。ただし、売れなければ、ずっと資産のまま、現金にならない。これが三枚目につながります」

「三上部長が買ってしまえば」

「部長一人では、七億八千万は買えません」

「テントだけなら」

「テントだけでも、無理です。会計上は」

　一画目。今日は早かった。

---

「三枚目、キャッシュフロー計算書」

```
キャッシュフロー計算書（CF）　前期
  営業活動によるキャッシュフロー     +205
    税引前利益                 318
    減価償却費                 +60      ← 現金は出ていないが費用にした分を戻す
    売掛金の増加               △140     ← 売上は立ったが、まだ現金になっていない
    在庫の増加                 △210     ← 現金で仕入れたが、まだ売れていない
    買掛金の増加               +85      ← 仕入れたが、まだ払っていない
    法人税の支払               △108
  投資活動によるキャッシュフロー     △115
    設備・ソフトウェアの取得    △115     ← 受注システム、AWS の初期費用など
  財務活動によるキャッシュフロー     △60
    借入の返済                 △60
  現金の増減                          +30
  期首現金                            380
  期末現金                            410
```

「PL の純利益は二億二千二百万でした。でも、現金は三千万しか増えてない。なぜか」

　梨乃は営業活動の行を見た。売掛金の増加、マイナス百四十。在庫の増加、マイナス二百十。

「売上は立ったけど、まだ入金されてない分と、仕入れたけど、まだ売れてない分」

「そうです。PL は『発生主義』で書きます。売ったときに売上、仕入れたときに原価。現金が動いたときではない。だから PL の利益と、現金の増減は、ずれる。そのずれを見せるのが CF です」

　橘は、三枚を並べた。

```
PL   一年間の、儲け        （発生主義。現金の動きとは違う）
BS   ある日の、持ち物と借金 （PL の利益が、利益剰余金として積み上がる）
CF   一年間の、現金の動き   （PL と BS の差から、現金がどこへ消えたかを示す）
```

「三枚は、つながってます。PL の純利益が、BS の利益剰余金に足される。BS の売掛金と在庫と買掛金の増減が、CF の営業活動に出る。一枚だけ見ると、必ず間違えます」

「一枚だけ見ると、どう間違えるんですか」

「PL だけ見る社長は、『利益が出てるのに、なぜ金がない』と言います。BS だけ見る銀行は、『在庫が多い』と言います。CF だけ見る人は、『利益が出てないのでは』と心配します。三枚で見て、初めて『利益は出てて、それが売掛と在庫に化けてて、現金には三千万しかなってない』とわかる」

「うちの社長は、どれを見ますか」

「PL の一番上の行だけです。体温だと思ってるので」

「……平熱、って言いますよね」

「言います。あれは、確定売上の前年比のことです。会計上は、売上高の成長率です」

　二画目。

　梨乃はノートに書いた。

> 三つの表。PL＝一年の儲け。BS＝ある日の持ち物と誰のものか。CF＝一年の現金の動き。
> PL は発生主義。売ったとき、仕入れたときに書く。現金が動いたときではない。
> 利益と現金はずれる。ずれの正体は、売掛金と在庫と買掛金。
> 在庫は資産。ただし、売れなければ現金にならない資産。部長でも買い切れない。
> 自己資本比率＝返さなくていいお金の割合。借りると下がる。
> （銀行は晴れの日に傘を貸す。社長の例えではないが、当たっている。部長は人件費）

## 第二章　黒字なのに現金がない

　八月、三友銀行との面談があった。

　担当者は、三枚の表を一時間見て、質問を三つした。三つだった。梨乃は、この会社に来る人はみんな三つで聞くのだろうか、と思った。

「売掛金が、前期比で百四十増えてます。理由は」

「丸嘉との取引が始まりました。丸嘉は、月末締めの翌々月末払いです」

　橘が答えた。

「在庫が二百十増えてます」

「丸嘉向けに、品揃えを増やしました。丸嘉の店舗が三倍になったので、欠品を防ぐために」

「ライズの買収後、ライズの在庫と買掛金も連結されます。ライズは、原材料の仕入れが現金払いで、ヤマビコへの納品は翌月末払いですね。ライズは、ヤマビコに売れば売るほど、現金が先に出てく会社です。三億のうち、いくらを運転資金に回しますか」

　橘は答えられなかった。大河内も答えられなかった。買収価格と、工場の設備更新しか、考えていなかった。

　銀行の担当者は、それを責めなかった。

「晴れの日ですから、今は」

　と言った。大河内が「傘だな」と言い、担当者が「傘です」と言った。二人の間で、何かが通じたらしかった。橘の眼鏡が、静かに上がった。

---

　面談のあと、橘は、梨乃を経理部の会議室に呼んだ。早瀬もついてきた。

「銀行が言ったことを、数字にします」

　橘は、一枚の表を書いた。

```
ヤマビコの現金の回転（丸嘉経由の靴一足、仕入 6,000 円、売値 9,000 円）

  Day 0     ライズから靴が届く。買掛金 6,000 が立つ（まだ払わない）
  Day 30    ライズに 6,000 を払う。現金 △6,000
  Day 45    丸嘉に売る。売掛金 9,000 が立つ。PL に売上 9,000、原価 6,000、粗利 3,000
  Day 105   丸嘉から 9,000 が入金。現金 +9,000

  現金が出てから戻るまで：Day 30 → Day 105 ＝ 75 日
  その間、一足あたり 6,000 円を、ヤマビコが立て替えている
```

「これを、キャッシュ・コンバージョン・サイクルと言います。仕入れの現金を払ってから、売上の現金が戻るまでの日数。七十五日」

「キャッシュ・コンバージョン・サイクル」

　早瀬が言った。

「現金が、変換される、周期。つまり、お金が靴になって、また、お金になって戻ってくるまでの時間」

　橘が、早瀬を見た。

「当たってます」

「当たりましたか」

「英語を訳しただけですが、当たってます」

　早瀬は「CCC（当たった・英語）」とメモした。三つ目だった。当たり方の種類が、増えてきていた。

「EC は」

　梨乃が聞いた。

「EC は、お客さんがカードで払って、決済代行から五日で入金です。Day 30 に払って、Day 45 に売れて、Day 50 に入金。二十日。丸嘉は七十五日。丸嘉の売上が増えるほど、立て替えの期間が長い商売の比率が上がる」

「売上が増えると、現金が減る」

「増えた分の粗利が現金になるのは、七十五日後です。その七十五日の間に、次の仕入れの支払いが来る。丸嘉向けの売上が月に五千万なら、原価は三千三百万で、七十五日分、つまり二か月半分の八千万を、常に立て替えてることになる」

「三上部長は、五日で入金されますよね」

「部長は、ヤマビコにとって、最も現金化の速いお客さんです。会計上は」

　三画目。

　橘は、もう一枚、表を出した。三枚あった資金繰り表のうちの、一枚だった。

```
資金繰り表（月次、今後 6 か月、単位：百万円）
              8月    9月    10月   11月   12月   1月
  期首現金     410    385    350    310    290    255
  入金
    EC        180    175    190    260    320    170   ← 12 月は年末商戦
    丸嘉        40     45     55     60     70     90   ← 2 か月遅れて入る
    法人        20     20     25     30     20     15
  出金
    仕入      △150   △160   △190   △230   △180   △130
    人件費     △45    △45    △45    △75    △45    △45   ← 11 月は賞与
    経費       △60    △60    △65    △70    △85    △65
    借入返済   △10    △10    △10    △10    △10    △10
    法人税      0      0      0     △25     0       0
    ライズ買収  0      0    △200     0      0       0   ← 10 月に実行予定
    ライズ運転資金 0    0    △50    △20    △20    △10
  期末現金     385    350    ★70    230    360    360
```

　十月の欄に、星印がついていた。

「買収を十月に実行すると、十月末の現金が七千万まで落ちます。十一月の人件費と賞与で七千五百万。足りません」

「三億借りるのでは」

「三億は、買収の二億と、工場の設備更新の一億の予定でした。運転資金を入れてない。銀行が今日、それを聞いた」

　梨乃は、資金繰り表を見つめた。PL では黒字だった。BS では自己資本比率五十六パーセントだった。それでも、十月に現金が足りなくなる。

「黒字倒産、というのは」

「これです。利益が出てて、資産もあって、現金がない。十一月の給料が払えなければ、会社は止まります」

「黒字なのに」

　早瀬が言った。

「黒字なのに、倒れる。黒いのに、倒れる……黒い倒れ方……」

「早瀬さん、今のは訳せない」

「訳せませんでした」

　早瀬は、当たったの記録の下に、小さく「黒字倒産（訳せず）」と書いた。

「橘さん、この資金繰り表、いつから作ってたんですか」

　梨乃が聞いた。机の上に三枚あったのを、思い出していた。

「三年前からです。誰にも頼まれてません」

「誰にも」

「経理は、頼まれなくても、資金繰り表を作ります。会計上は、それが趣味です」

　四画目。趣味、だった。

---

「どうするんですか」

「四つあります」

　橘は書いた。

```
1. 借入を三億五千万にし、五千万を運転資金枠にする       → 銀行と交渉
2. 丸嘉に、翌々月末払いを翌月末払いに変えてもらう          → 三上が交渉。難しい
3. 在庫を減らす。丸嘉向けの品揃えを、売れ筋に絞る          → 志村と森田
4. ライズへの支払いを翌月末から翌々月末にする              → 買収後は同じグループ。連結では相殺されるが、ライズ単体の現金が減る
```

「三と四は、経営の判断です。一は私がやります。二は三上さんに頼みます」

「三上さんが、丸嘉に電話するんですね」

「電話します。三上さんは、電話に強い」

「本人が言いそうですね」

「本人が言いました。さっき」

「橘さんの仕事は、決算だと思ってました」

　橘は、少し笑った。

「決算は、経理の仕事です。今やってるのは、財務の仕事です」

```
経理   過去を記録する。売上、仕入、経費を正しく帳簿に書き、三つの表を作る
財務   未来の現金を管理する。いつ、いくら足りなくなるかを予測し、借りるか、回収を早めるか、支払いを遅らせるか、を決める
```

「ヤマビコは、財務を誰もやってませんでした。現金が足りなくなったことがなかったからです。三億借りて、ライズを買って、丸嘉の売上が増えて、初めて足りなくなる」

「橘さんは、三年前から、趣味で財務をやってた」

「趣味でした。今日から、仕事になりました」

　橘は、資金繰り表を、毎週更新することにした。梨乃は、それを経営会議の最初の議題にすることにした。

　三上は、丸嘉と二週間交渉し、「翌々月末」を「翌月二十日」に縮めた。電話を十一回かけた。七十五日が五十日になった。志村は、丸嘉向けの品揃えを四十点から二十八点に絞った。絞るときに、落とした十二点それぞれについて、一言ずつ何か言った。銀行は、運転資金枠五千万を承認した。十月末の現金の見込みは、七千万から一億九千万に戻った。

　星印は、消えた。

　梨乃はノートに書いた。

> キャッシュ・コンバージョン・サイクル＝現金を払ってから戻るまでの日数。売上の中身で違う。お金が靴になって戻る（早瀬・当たり）。
> 売上が増えると、現金が減ることがある。立て替えが増えるから。
> 資金繰り表＝月ごとの入金と出金と期末現金。星印を探す。橘さんは三年前から趣味で作っていた。
> 黒字倒産＝利益と資産があって、現金がない。給料が払えなければ止まる。訳せない。
> 経理は過去の記録。財務は未来の現金。
> （銀行は傘を貸した。三上部長は電話を十一回かけた）

---

## 第三章　月次決算の五日間

　九月、梨乃は橘に頼んで、月初の五日間、経理部に張り付いた。受注システムのために現場を数えたのと同じことを、経理でやりたかった。

「五日間、私の隣に座るんですか」

「はい」

「私は、隣に人がいると、正の字を書きます」

「……何のですか」

「梨乃さんが議事録に書いてる、あれです。私も数えてます。梨乃さんが私を見て何かメモした回数を」

  経費精算の集計・突合             48h      経費精算 SaaS。領収書をスマホで撮影、承認、会計に自動連携

　小野は、一週間で、三社の帳簿と、SSC の手順と、システムを見た。最終日に、指摘事項を三十九件、一枚の表にして持ってきた。

```
指摘事項（抜粋）
  重要度  項目                                  内容
  高      ライズの在庫評価                       実地棚卸が年 1 回。月次の在庫金額は推定。4 月からの毎月計上は評価
  高      売上計上基準の文書化                    EC・丸嘉・法人で計上時点が異なる。文書化されていない
  高      アクセス権限の棚卸し                    会計システムの管理者権限が、橘・岡崎・赤海の 3 名。赤海は経理ではなく、社員でもない
  高      外部委託契約の実態と契約書の乖離        夜座コンサルティングとの契約。件名「調査」、月額「適宜」、期間 3 年。実態はデータ基盤の構築・運用
  中      職務分掌                               ライズの購買で、発注承認と支払承認が同一人（熊谷）の取引が過去 2 年に 312 件
  中      減価償却の台帳                          Excel 管理。取得価額の根拠資料が一部見つからない
  中      管理会計と財務会計の整合                Snowflake の売上と会計システムの売上が、月末に手で合わせている。差異の記録がない
  中      月次決算の証跡                          仮締め後の修正仕訳が、誰の判断で入れられたか記録がない
  低      経費精算                               領収書の原本が一部見つからない（SaaS 導入前）
  ...
```

　四つ目の「高」を読んだとき、小部屋の全員が、同時に岡崎を見た。岡崎は、目を伏せなかった。まっすぐ、小野を見ていた。

「四つの『高』から説明します」

　小野は言った。

「一つ目、ライズの在庫。四月から毎月出してるのは良い。ただし、毎月の数字が実際の在庫と合ってるかを、抜き取りで確認してますか」

「してません」

「してください。監査では、私が倉庫に行って、棚から十点を選んで数えます。帳簿と合わなければ、在庫金額全体を疑います」

「印影の確認ですね」

　岡崎が言った。小野が、岡崎を見た。

「……そういう言い方も、できます」

「二つ目、売上計上基準。EC は決済完了日、丸嘉は出荷日、法人は検収日。三年前に決めたと聞きました。それは正しい。ただ、その決定が、どこに書いてありますか」

　橘は、赤海を見た。赤海が答えた。

「dbt の fact_orders の SQL に、CASE 文で書いてあります」

　小野は、初めて表情を変えた。

「それは、システムの中に書いてある、ということですね。監査人が読める文書として、『売上計上基準』を一枚、作ってください。SQL は、その文書の実装です。文書がなく実装だけあると、実装が変わったときに、誰が承認したかわからない」

「十行の CASE 文が、正本だと思ってました」

　梨乃が言った。

「十行の CASE 文は、写しです。正本は、社長が承認した文書です」

「……三年、写しを正本だと思ってました」

「よくあります」

「三つ目、アクセス権限。会計システムの管理者が三人で、うち一人は経理ではなく、社員でもない。赤海さんは、なぜ管理者ですか」

「三年前、Snowflake との連携を作るときに、管理者権限が必要でした。そのままです」

「今も必要ですか」

　赤海は少し考えて、言った。

「必要ありません。連携用のアカウントを別に作れば、私の管理者権限は外せます」

「外してください。そして、半年に一度、『誰がどの権限を持ってるか』を棚卸しして、記録を残してください」

「四つ目」

　小野は、そこで、少しだけ間を置いた。

「夜座コンサルティングとの契約。件名が『調査』で、月額が『適宜』で、三年続いてます。契約書には、調査の対象も、成果物も、期間も書いてありません。一方で、この一週間、私が見た御社のシステムの、ほぼ全部を、赤海さんが作ってます。契約書と実態が、まったく合ってません」

　小部屋が静かになった。串の缶が、六つあった。

「これは、監査上、問題になります。上場審査でも、問題になります。『社員でない人が、契約書に書いてない仕事で、会社の基幹を作った』という状態です。赤海さんが明日いなくなったとき、会社は夜座に何を請求できるのか。夜座は会社に何を請求してるのか。どちらも、答えられません」

「……答えられません」

　岡崎が言った。

「岡崎さんは、知ってましたね」

「知ってました。三年前から」

「なぜ、直さなかったんですか」

　岡崎は、少し息を吸った。

「直そうとすると、赤海さんの仕事を、全部、契約書に書かなければならなくて。全部を書ける人が、私しかいなくて。書き始めたら、三十ページになって。三十ページの契約書を、社長に持っていく勇気が、なくて」

「三十ページ」

「今、四十二ページです」

　岡崎は、鞄から、分厚い封筒を出した。

「三年、書いてました」

　小野は、それを受け取って、十分間、読んだ。

「これは、契約書ではなく、業務仕様書です。ただし、良い仕様書です。これを添付して、契約書の件名を『データ基盤の構築および運用支援』に変え、月額を固定し、期間を一年更新にしてください。それで、指摘は消えます」

「件名を、変えるんですか」

　赤海が言った。三年ぶりに、赤海が動揺したのを、梨乃は見た。

「変えます。『調査』は、三年前の一週間で終わってます」

「……調査の一環、が使えなくなる」

「使えなくなります。『支援の一環』になります」

　佐藤が、Slack に書いた。#ssc-finance だった。

「請求書に、載りますか」

　橘が返した。

「載ります。会計上、支援費として」

「よかったです」

　佐藤は、それだけ書いた。三年分の「よかったです」だった。

---

「中の指摘で、一つ聞きたいことがあります」

　梨乃が言った。

「管理会計と財務会計の整合。Snowflake と会計システムの売上を、橘さんが毎月、手で合わせてます。それは、悪いことですか」

「手で合わせること自体は、悪くありません。悪いのは、合わせた結果、いくら差があって、なぜ差があって、どちらを直したかの記録がないことです。私が監査で見るのは、『Snowflake の売上が四億一千八百万、会計システムが四億一千七百六十万、差額四十万は返品の計上月のずれで、翌月に会計側で修正』という一行です。その一行があれば、二つの数字が違ってても、問題ありません」

「記録があれば、いい」

「監査は、正しいかどうかを見るのではなく、正しいと言える根拠が残ってるかを見ます。三年前、皆さんが『三つの売上』を一つにした。あれは、定義を決めたことに価値があるのではなく、決めた定義を一か所に書いて、全社がそれを使ったことに価値がある。それを、紙にしてください」

　赤海が、小さく言った。

「正本と写しの話だ」

　小野は、赤海を見た。

「その言い方は、初めて聞きました。監査人の言葉では、『証跡』と『統制』です。同じことを言ってます」

「赤海語録に、小野語録が入りました」

　桐山が言った。小野は、「語録？」と聞き、桐山は「あります」と答え、小野は「監査法人にも、あります。『指摘事項集』と言います」と言った。

---

　八月、橘は三十九件の指摘に対応した。

　売上計上基準は、三ページの文書になり、大河内が承認した。fact_orders の SQL の先頭に、その文書の版番号がコメントで書かれた。赤海の管理者権限は外され、連携用アカウントが作られた。ライズの在庫は、毎月、熊谷と佐藤が二十点を抜き取って数えることになった。熊谷は「四十年、一足も間違えてない」と言い、初回の抜き取りで、一足も間違っていなかった。減価償却台帳は、固定資産管理 SaaS に移された。Snowflake と会計システムの差額は、毎月、一行の記録が残ることになった。

　そして、夜座コンサルティングとの契約書が、書き直された。

```
件名        データ基盤の構築および運用支援
期間        一年（自動更新）
月額        固定（岡崎の四十二ページの仕様書に基づく）
成果物      別紙仕様書のとおり
契約担当    岡崎
```

　岡崎は、契約書に印を押した。三年ぶりに、印影を確認した。

　赤海は、新しい契約書を三分読んで、言った。

「支援の一環だ」

「支援の一環です」

　岡崎が言った。

「からあげ棒は、支援に含まれますか」

「含まれません。会計上は」

　橘が言った。十四画目。相殺後、五。

　九月、小野がもう一度来て、三十九件のうち三十二件が対応済みであることを確認した。残り七件は、「来年四月までに」だった。

「一つだけ、聞かせてください」

　小野は帰り際に、橘に言った。

「経理四人、SSC 六人で、三社の月次を五日で締めて、監査のショートレビューに三十九件で済んだ会社を、私は初めて見ました。何をしたんですか」

　橘は、少し考えてから言った。

「三年前に、経営企画の若い人が、『先月の売上』を一つの数字で答えられなかった。それを直すところから始めて、直すたびに、一枚ずつ、正本を作った。私がやったのは、その七枚目です」

「七枚目」

「壁に貼ってあります。行けば、わかります」

　小野は、小部屋の壁を見に行った。七枚の図と、三十枚の付箋があった。「※三上部長は一人」を、小野は三十秒見ていた。

「この付箋は、統制上、何ですか」

「……証跡です」

　梨乃が答えた。小野は、それ以上、聞かなかった。

　梨乃はノートに書いた。

> 監査は、正しいかどうかではなく、正しいと言える根拠が残っているかを見る。健康診断（社長・自覚あり）。
> 決めたことは、システムの中だけでなく、人が読める文書にする。文書が正本、SQL が実装。十行の CASE 文は写しだった。
> 権限は、半年に一度、棚卸しして記録する。必要なくなった権限を外す。
> 二つの数字が違ってもいい。差額と理由と直した先を、一行で記録する。
> 証跡と統制。監査人の言葉で、正本と写し。
> （契約書の件名が、三年ぶりに変わった。岡崎さんは四十二ページ書いていた。佐藤社長は「よかったです」と書いた。調査の一環は、支援の一環になった）

## 終章　七枚目の図

　十月、月次決算は、三社合わせて三日で仮締め、五日で確定した。SSC の六人で、三百十時間だったものが、百二十時間になっていた。橘の五十時間は、三十時間になり、そのうち二十時間は、資金繰り表と、来年の予算と、監査対応に使われていた。

「趣味が、仕事になったので、新しい趣味を探してます」

　橘は言った。

「何を」

「予算の三年計画です。誰にも頼まれてません」

「それは、趣味ですか」

「趣味です。会計上は」

　十五画目。相殺後、六。

　熊谷は、十一月で退職することになった。最後の月、熊谷は野村と新卒に、長野の部品屋の FAX の癖——どの会社が数量を漢数字で書くか、どの会社が消費税を別に書くか——を、三日かけて教えた。それは、AI-OCR が九割五分を読んだあとの、五分の部分だった。

「四十年分の、五分か」

　熊谷は、そう言って笑った。

「五分は、一番難しいところです」

　野村が言った。会計上は、とは付けなかった。付けなくていい場面だと、わかっていた。

　熊谷は、最終日に、赤海からからあげ棒を受け取った。食べた。

「おいしいね」

「褒めてるんです」

「知ってる。伝票の話を、四十分聞いてくれたから」

　赤海が四十分聞いていたことを、梨乃は初めて知った。

---

　十一月、赤海は早瀬に、いつもの問いを投げた。壁には七枚目の図が貼ってあった。

「ライズの部品屋から、請求書が一枚届いた。それが、社長の見る数字になるまで」

　早瀬は、図の前に立った。

「請求書は、長野の SSC 受付に紙で届きます。パートさんがスキャンして、二百 dpi で、請求書 SaaS に入れます。AI-OCR が、取引先と金額とインボイス番号を読みます。取引先は xref_supplier で正本に紐づき、番号は国税庁と照合されます。読めなかった五分は、野村さんが見ます。熊谷さんの三日間の引き継ぎがあります」

「請求書は、購買システムの発注と検収と、三点照合されます。合えば、統一勘定科目で、クラウド会計 A に仕訳が入ります。承認は、ライズの新社長が、発注者とは別の人として、Entra ID でログインして押します。承認のログが残ります。三上部長ほどじっくりではありませんが、残ります」

「支払日に、銀行 API で振込が実行されます。仕訳は、その夜、レイクにコピーされ、翌朝、dbt が Snowflake の経理マートに並べます。会計システムの数字と Snowflake の数字は、月末に橘さんが一行で突き合わせて、差額と理由を記録します。三年間、記録がなかった一行です」

「月初三日目、三社の仮の PL と BS と資金繰り表が、Power BI に出ます。社長は、それを見ます。体温を見ます。五日目に確定します。来年四月からは、小野さんが、この全部の証跡を見ます。付箋も、証跡です」

　赤海は、椅子を回した。

　からあげ棒を、早瀬に差し出した。早瀬は食べた。

「支援の一環ですか」

「支援の一環だ」

　早瀬は、少し間を置いて、聞いた。

「赤海さん。一枚目の図は、注文が棒グラフになるまででした。七枚目は、請求書が PL になるまでです。同じ形ですね」

「同じ形だ。発生源があって、正本があって、写しがあって、見る人がいる。売上も、商品も、人も、通信も、サーバーも、業務も、請求書も、全部それだ。七枚描いて、やっと、それが一つの形だとわかる」

「契約書も、同じ形でしたね」

「……契約書も、同じ形だった」

「岡崎さんの四十二ページが、正本で、『調査』が写しだった」

「三年、写しで動いてた」

「よく動きましたね」

「岡崎さんがいたからだ」

　赤海は、そう言って、串を缶に立てた。缶は六つで、そろそろ七つ目が要りそうだった。

---

　梨乃はその夜、ノートの最後のページに書いた。

> 三つの表。PL は儲け、BS は持ち物と誰のものか、CF は現金。三枚で見る。社長は一行目だけ見る。
> 利益と現金はずれる。売掛と在庫と買掛に化ける。黒字倒産はここで起きる。訳せない。
> 経理は過去の記録、財務は未来の現金。資金繰り表に星印を探す。橘さんの趣味だった。
> 減価償却＝買ったものを使う期間に分ける。作ったものは資産、借りたものは費用。部長のテントは載らない。
> 財務会計は外向きでルールあり。管理会計は内向きでルールは自分で決める。平熱は橘さんが決めた。
> グループになると、同じ仕事が会社の数だけ手順を持つ。SSC＝集約・標準化・自動化。センターは強くない。
> 寄せるのは処理。判断は各社。遠い SSC には SLA とチャージバック。長野は本当に遠い。
> 職務分掌。正直な人がいるから、ではなく、仕組みで。熊谷さんは四十年一円も。
> 自動化の前に標準化。RPA は手順を固める。API がなければ、システムを替える。フロッピーに API はない。
> 監査は、正しいかではなく、根拠が残っているかを見る。決めたことを文書に。差額を一行に。
>
> 七枚の図は、一つの形だった。
> 発生源、正本、写し、見る人。
> 契約書も、同じ形だった。岡崎さんの四十二ページが正本で、「調査」が写しだった。
> 一枚目に「集計に使うな」と書いたとき、七枚目の請求書のことは、知らなかった。
> 一枚ずつでいい。ただし、一枚目に、本当のことを書く。
> （相殺後、六。佐藤社長は「よかったです」。調査の一環は、支援の一環に。串の缶は七つ目が要る）

## 付録　登場した仕組みと用語

| 物語での呼び方 | 正式名称 | 役割 |
|---|---|---|
| 三つの表 | 財務諸表（PL / BS / CF） | 儲け、持ち物と調達元、現金の動き。三枚でつながる。この会社は三つが好き |
| 売ったときに書く | 発生主義 | 現金の動きと切り離す。利益と現金がずれる原因 |
| 返さなくていいお金の割合 | 自己資本比率 | 純資産 ÷ 総資産。借りると下がる |
| 晴れの日の傘 | 借入と銀行の関係 | 昔からある言葉。社長のものではないが当たっている |
| 現金が化けた先 | 運転資本（売掛金・在庫・買掛金） | CF の営業活動に出る。部長でも買い切れない |
| お金が靴になって戻る | キャッシュ・コンバージョン・サイクル | 売上の中身（EC / 丸嘉 / 法人）で日数が違う。早瀬が当てた回（英語） |
| 星印 | 資金繰り表 | 月次の入出金と期末現金。足りなくなる月を先に見つける。橘さんの趣味 |
| 黒いのに倒れる | 黒字倒産 | 利益・資産があって現金がない。訳せない |
| 過去と未来 | 経理と財務 | 記録する仕事と、現金を予測・調達する仕事 |
| 五日間 | 月次決算 | AP・AR・経費・給与・在庫・償却・未払前払・仮締め・報告。志村さんへの確認は靴紐込み |
| 使う期間に分ける | 減価償却 | 作ったものは資産計上、借りたもの（SaaS）は費用。部長のテントは私物 |
| 外向きと内向き | 財務会計と管理会計 | ルールが決まっている会計と、判断のための会計。平熱は管理会計 |
| 三社を足す | 連結 | 各社の締めが揃わないと足せない。体温も足せない |
| 三人の橘 | 間接業務の重複 | 会社の数だけ手順がある。名寄せはされない |
| センター | シェアードサービスセンター（SSC） | 経理・人事・総務・購買・情シスの処理業務を集約。強くない |
| 順番 | 集約・標準化・自動化 | 集約だけでは楽にならない。標準化しないと自動化できない |
