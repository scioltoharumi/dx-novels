# 二十三本の川

## 第一章　河口

　月初の第四営業日、午後十一時。

　大鳥ビジネスサービスの九階からは、多摩川の河口が見える。昼は灰色の水が海に広がっていて、夜は羽田の誘導灯だけが見える。湊早紀は、六年間その窓の前に座ってきたが、川を見たことはあまりなかった。見ているのは、いつも画面の中の一行だった。

```
06/05  三友銀行 川崎支店  普通 1234567
  振込  カ）カモメストア          ¥18,442,316
```

　一千八百四十四万二千三百十六円。どの請求に当たるのかが、分からない。

　大鳥ビジネスサービスは、大鳥ホールディングスのシェアードサービス会社である。グループ十六社の経理・人事・購買の処理を引き受けていて、湊はその中の入金消込チームのリーダーだった。チームは十四人。十四人で、グループ十六社の売掛金に、毎月一万八千行の入金を当てていく。

　入金消込とは、銀行に入ってきたお金が、どの請求の支払いなのかを突き合わせて、売掛金を消していく仕事である。請求が百万円で、入金が百万円なら、終わる。終わらないものが、毎月一万行ある。

「湊さん、それ、カモメさんのやつですか」

　隣の席の古賀が言った。古賀は六十歳の嘱託で、入金消込を二十八年やっている。机の上には、銀行明細を印刷した紙と、先の丸い鉛筆と、名義帳があった。名義帳は Excel のファイルで、四千二百十二行ある。振込名義のカナと、それがどの会社のどの顧客なのかの対応が、二十八年分書いてある。

「カモメさんです。フーズの請求は千九百十二万で、どう足しても合わないんです」

「カモメさんは、フーズだけじゃないですよ。ロジの運賃も一緒に払ってきます」

「ロジも」

「ロジも。あと、協賛金とセンターフィーが引かれてます。センターフィーは納品額の三パーセント弱。協賛金は月によって違う」

「どうして分かるんですか」

「癖です」

　古賀は、鉛筆で明細の紙に小さく丸をつけた。

「カモメさんの癖。毎月五日に、大鳥さん宛ての分をまとめて一本で払う。カモメさんから見たら、うちは『大鳥』一社なので」

　湊は、画面を見た。カモメストアの売掛金は、大鳥フーズに十二件、大鳥ロジスティクスに四件あった。二つの会社は、別の会計システムを使っていた。

---

　その日の午後、一本の電話があった。

　カモメストアの経理部長から、大鳥フーズの社長にかかってきた電話だった。

「三月分の運賃を、払ったのに督促状が来た。御社はどうなっているのか」

　督促状は、大鳥ロジスティクスから出ていた。ロジは、SSC の消込が終わった後の売掛金の残高を見て、期日を過ぎた未入金に督促状を送る。ロジの売掛金には、カモメストアの三月分が残っていた。

　大鳥フーズの社長は、ホールディングスの財務担当役員に電話した。財務担当役員は、SSC の社長の真壁に電話した。真壁は、翌朝九時に、湊を社長室に呼んだ。

「消込が遅いから、督促が間違えて出る」

　真壁は言った。五十代の半ばで、ホールディングスの経営企画から二年前に SSC に来た。前任の SSC 社長は、経理の人だった。真壁は、経理の人ではなかった。

「来期から、消込は AI でやる。AI エージェントというやつだ。AI で、人は半分にする」

「半分」

「半分。ホールディングスの中期計画に、そう書いた。間接部門の生産性、二倍」

　湊は、中期計画に自分のチームの人数が書かれていることを、そのとき初めて知った。

「AI で、どこまでできるんでしょうか」

「それを決めるのが、君の仕事だ。外から一人、来てもらう」

---

　社長室を出ると、湊の後ろから、二年目の栗原がついてきた。社長室の前で待っていたらしい。

「社長、何回言いました」

「何を」

「AI で、です」

「……二回」

　栗原は、ポケットから付箋を出して、正の字の一画目と二画目を書いた。栗原は、生成 AI が好きだった。好きな人が、社長の口癖を数えていた。

「AI、使えますよ。僕、この前、振込名義を読ませてみたんです。けっこう当たります」

「けっこう、って何割」

「……けっこうです」

---

　外から来た一人は、その日の午後に来た。

　夜座コンサルティングの鷺沼と名乗った。背が高く、ステンレスの水筒を持っていた。中身は麦茶だった。名刺には「シニアコンサルタント」とだけあった。

　鷺沼は、SSC のフロアを一周してから、入金消込チームの島の、いちばん窓側の端の席に座った。空いていたのが、そこだけだった。

「この席は」

「消込の、最後の人の席です。仮受金を見る人の席」

「仮受金」

「どの請求にも当てられなかった入金を、いったん置いておく場所です」

「置いておく場所」

　湊は、手元の紙に、仕訳を二つ書いてみせた。

```
当たったとき     普通預金 1,000,000 ／ 売掛金 1,000,000      売掛金が消える。これが「消込」
当たらないとき   普通預金 1,000,000 ／ 仮受金 1,000,000      売掛金は残ったまま。入金は仮受金に置く
```

「当たらないと、お金は入っているのに、売掛金が残ります。帳簿の上では、払っていない顧客に見える。期日を過ぎれば、督促状の対象になります。仮受金のほうは、誰のお金か分からないまま、決算のたびに説明を求められる」

「置いておくだけでは、済まない場所ですね」

　鷺沼は、麦茶を一口飲んだ。

「では、ここが河口ですね」

　湊は、窓の外を見た。多摩川が、灰色に広がっていた。

「湊さん、一つだけ、教えてください」

　鷺沼は、湊の画面の一行を指した。カモメストア、一千八百四十四万二千三百十六円。

「この一行は、どこで生まれましたか」

「……三友銀行の、川崎支店です」

「銀行は、運んだだけです。この金額は、どこで決まりましたか」

　湊は答えられなかった。

　古賀が、隣から言った。

「カモメさんの、経理です。カモメさんの経理が、うちへの支払いを計算して、そこから協賛金とセンターフィーを引いて、この金額にした」

「カモメさんの経理は、何を見て、協賛金を引きましたか」

「それは……フーズの営業と、カモメさんのバイヤーが、商談で決めたもの」

「その決めたものは、今、どこにありますか」

「たぶん、フーズの営業の人の、メールの中です」

　鷺沼は頷いた。

「では、この一千八百万の中身を、いちばんよく知っているのは、この川の、ずっと上にいる人です。古賀さんは、それを、癖から逆算している」

「逆算、というか」

　古賀は鉛筆を置いた。

「二十八年、見てるので」

「二十八年、河口で、上流の天気を当ててきた」

　鷺沼の言い方に、嫌味はなかった。古賀は、少し黙ってから、「まあ、そうです」と言った。

　湊はノートに書いた。

> 入金消込＝入ってきたお金が、どの請求の支払いかを当てて、売掛金を消すこと。
> 当たらないものは仮受金に置く。仮受金は河口。売掛金は残ったままなので、払った顧客が払っていない顧客に見える。
> 一行の入金には、上流の決めごと（まとめ払い、控除、相殺）が全部溶けている。
> 「この一行は、どこで生まれましたか」。銀行は運んだだけ。
> 古賀さんは、癖から逆算している。二十八年。名義帳、四千二百十二行。
> （社長の「AI で」、初日に二回。栗原の付箋）

---

## 第二章　二十三本の川

　鷺沼が最初に頼んだのは、請求書を出している単位を、全部書き出すことだった。

「会社の数ではなく、請求書を出している単位です。同じ会社でも、請求を作るシステムや人が違えば、別に数えてください」

　湊と古賀と栗原で、三日かけて書き出した。十六社のうち、いくつかの会社は、事業部ごとに請求の出し方が違った。

```
大鳥グループの請求元（入金が SSC に流れてくる単位）

  会社                  請求元                     入金の形
  大鳥工業（製造）       産業機器 / 部品 / 保守      振込・手形・でんさい・一括ファクタリング
  大鳥化成（素材）       化成品                     振込・でんさい。相殺あり

  大鳥リビング（不動産） 賃貸 / ビル管理             口座振替（収納代行）・振込・保証会社
  大鳥リテール（小売）   EC / 卸                    決済代行（カード・コンビニ・後払い）・振込
  大鳥システムズ（IT）   SaaS / 受託開発             カード（決済代行）・振込。年払いの前受
  大鳥ロジスティクス     運賃                       振込。荷主のまとめ払い

  大鳥ファイナンス       リース                     口座振替
  大鳥スポーツ           フィットネス会費            口座振替（収納代行）
  大鳥ホテルズ           宿泊                       旅行サイトからの振込（手数料控除）・カード
  大鳥パーキング         駐車場                     決済代行・振込
  大鳥エナジー           売電                       電力会社からの振込
  大鳥ホールディングス   グループ内の経営指導料       グループ各社からの振込

  → 16 社、23 の請求元
```

「二十三本」

　鷺沼は、表の一番下の数字に丸をつけた。

「二十三本の川が、ここ一か所に流れ込んでいる」

「口座も、多いです」

　湊は、次の紙を出した。

```
入金口座     7 行・38 口座（各社・各事業部が、それぞれに開いた）
会計システム 5 種類（工業・化成・商事は SAP、中小 9 社は同じパッケージ会計、
                    リビングは賃貸管理システム、システムズは請求管理 SaaS、HD は SAP の別環境）
入金明細     月 18,400 行
自動消込     41%（会計システムの標準機能。金額と名義が完全に一致したものだけ）
手作業       月 10,900 行。チーム 14 人
締め         消込の締めは第 6 営業日。ホールディングスの連結は第 3 営業日で欲しいと言っている
仮受金       3 億 1,200 万円・1,380 件。いちばん古いものは 26 か月前
```

「二十六か月前の入金は、何ですか」

「分かりません。分からないので、二十六か月、仮受金にいます」

　鷺沼は、麦茶を飲んだ。

「河口に、二十六か月、沈んでいる」

---

　次の二週間、鷺沼は、消込チームの十四人の横に、一人ずつ座った。

　何をしているかは、聞かなかった。聞いたのは、「今のは何ですか」だけだった。画面を切り替えたとき、電話を取ったとき、メールを書き始めたとき、鉛筆で丸をつけたとき。

「今のは何ですか」

「名義帳を検索しました。『オオトリコウギヨウ』で、うちの工業のことです」

「自分の会社から、入金があるんですか」

「工業が、グループ内の請求をまとめて払ってきます。工業の中の三つの事業部の分を、工業の本社が一本で」

「今のは何ですか」

「リビングの賃貸の担当者に、メールです。収納代行の明細ファイルを送ってください、って。毎月送ってもらうんですけど、毎月送ってくれないので」

「今のは何ですか」

「電卓です。商事の米ドルの入金が、請求額より三十五ドル少ないので。途中の銀行の手数料だと思うんですけど、それを為替差損にするか、支払手数料にするか、商事に聞かないといけないので」

　鷺沼は、ノートに小さな正の字を書いていった。問い合わせの数だった。二週間で、グループ各社への問い合わせは九百四十件あった。一か月に直すと、千九百件。返事が来るまで、平均で三・二日かかっていた。

「消込の仕事の半分は、聞くことですね」

「聞かないと、分からないので」

「分からないのは、なぜですか」

「……書いてないからです」

　湊がそう答えると、鷺沼は少し笑った。

「それを、今から数えます」

---

　栗原が、会議室の入口で待っていた。

「鷺沼さん、数えるのもいいんですけど、先に AI を作ったほうが早くないですか。僕、試しに作ったやつがあるんです。振込名義と金額を読ませると、候補の請求を出してくれる」

「どれくらい当たりますか」

「八割、くらい」

「残りの二割は、どういう入金ですか」

「……それは、まだ見てないです」

「では、それを見てからにしましょう。数える前に作ると、何が当たったのか、分からない」

　栗原は、付箋の束を握ったまま、少し不満そうだった。

「社長は、今日、三回言いました」

「何を」

「AI で、を」

　付箋の正の字は、一つ完成していた。

---

　手作業の一万九百行を、一か月分、全部、理由で分けた。一行に理由が二つあるものは、主な方に入れた。湊と古賀と栗原と、鷺沼の四人で、四日かかった。

```
手作業になった理由（1 か月・10,900 行）           件数     時間     1行あたり
  1  名義が顧客マスタと合わない                  2,840    310h      7 分
     （略称・48 文字で切れる・旧社名・個人名・親会社の支払代行）
  2  同じ会社の複数の請求をまとめて払っている      1,960    290h      9 分
  3  手数料が引かれている                        1,720    140h      5 分
     （振込手数料・海外送金の中継手数料・決済代行の手数料）
  4  控除・相殺・リベートが引かれている            1,180    590h     30 分
     （協賛金・センターフィー・返品・リベート・買掛金との相殺）
  5  請求の遅れ・誤り（請求前の入金、請求額の訂正） 880    150h     10 分
  6  複数のグループ会社の分をまとめて払っている      610    300h     30 分
  7  一部だけの入金・分割・払いすぎ・二重払い        540    180h     20 分
  8  収納代行・口座振替の一括入金の分解              420    110h     16 分
  9  外貨（為替差・海外の手数料）                   310     90h     17 分
  10 手形・でんさい・一括ファクタリング             260     60h     14 分
  11 どれにも当たらない                           180    120h     40 分
                                           合計  10,900  2,340h
```

　湊は、その表を見て、しばらく黙った。

「件数で一番多いのは、名義です。でも、時間で一番重いのは、控除と、グループ合算」

「件数の順番と、時間の順番が違う」

　鷺沼は、四番と六番に線を引いた。

「控除とグループ合算は、合わせて千八百行。全体の六分の一です。それが、時間では四割を食っている」

「自動消込率は、四十一パーセントです」

「その四十一パーセントは、たぶん、もともと一分で終わる入金です。自動消込率を上げようとすると、簡単なものから順に自動になる。三十分かかる入金は、最後まで残る」

「では、何を見れば」

「時間です。それと、河口に沈んでいる期間」

　古賀が、鉛筆で表の十一番を叩いた。

「どれにも当たらない百八十件。これが、二十六か月になる」

「その百八十件は、古賀さんでも分からない」

「分からないです。癖がない。一回だけ払ってきた会社とか、個人とか」

　鷺沼は、しばらく表を見ていた。それから、ホワイトボードに一本の線を引いた。左に「上流」、右に「河口」と書いた。

「今日は、ここまでにします。明日から、この十一の理由が、それぞれ、どこで生まれているかを見に行きます」

「上流へ」

「上流へ。二十三本、全部は無理なので、時間の重い順に」

　湊はノートに書いた。

> 請求元＝請求書を出している単位。会社の数とは違う。二十三本の川。口座三十八、会計システム五種類。
> 業務量調査は「何をしていますか」ではなく「今のは何ですか」で拾う。
> 消込の半分は「聞くこと」。月に千九百回、平均三・二日待つ。聞くのは、書いていないから。
> 件数の順番と時間の順番は違う。控除とグループ合算は件数の六分の一で、時間の四割。
> 自動消込率だけを追うと、簡単なものから自動になる。重いものは最後まで残る。
> 「どれにも当たらない」百八十件が、仮受金の底に沈む。
> （社長の「AI で」、累計五。付箋の正の字が一つ完成した）

## 第三章　どこで生まれたか

　最初の上流は、大鳥フーズだった。控除の時間が、いちばん重かったからだ。

　フーズの量販営業課の羽鳥は、四十代の課長で、カモメストアの担当だった。督促状の件で、カモメの経理部長に三回頭を下げたばかりだった。

「協賛金ですか。毎月、カモメさんのバイヤーと決めてます。来月の特売に何ケース出すから、協賛金はいくら、と」

「決めた金額は、どこに書きますか」

　鷺沼が聞いた。

「メールです。バイヤーさんから、確認のメールが来るので」

「そのメールは、SSC に届きますか」

「届かないです。届けたほうがいいんですか」

「控除の金額を、SSC はどうやって知っていますか」

　羽鳥は、湊を見た。湊は古賀を見た。古賀は、少し困った顔で言った。

「カモメさんのサイトに、支払案内が出るんです。取引先向けのサイト。そこに、何をいくら引いたかの明細が載る。フーズの営業さんが ID を持ってるので、毎月、ダウンロードして送ってもらってます」

「送ってもらえていますか」

「羽鳥さんは、送ってくれます。三回に一回くらい」

　羽鳥は、頭をかいた。

「すみません。月初は、店回りなので」

「羽鳥さんが悪いのではないです」

　鷺沼は言った。

「羽鳥さんの仕事は、カモメさんに商品を売ることです。支払案内を SSC に送ることは、羽鳥さんの仕事として、どこにも書かれていない。書かれていない仕事は、忙しい月から順に抜けます」

---

　鷺沼は、ホワイトボードに一本の川を描いた。上流から河口へ、四つの点を置いた。

```
  上流                                                         河口
  商談 ───→ 請求 ───→ 顧客の支払処理 ───→ 銀行 ───→ SSC の消込
  （営業）   （各社）    （顧客の経理）       （運ぶだけ）  （当てる）

  協賛金の合意  →  請求書には載らない  →  カモメが支払額から引く  →  金額だけが届く  →  古賀さんが逆算する
  （羽鳥さんのメール）                    （明細はカモメのサイト）
```

「情報は、生まれている。商談のときに、協賛金はいくら、と決まっている。でも、その情報は、請求書に載らずに、営業のメールの中で止まる。カモメさんのほうは、それを引いて払う。河口には、引いたあとの金額だけが届く」

## 第四章　清流化

　七月の最初の月曜、湊は、ホワイトボードの前に立った。鷺沼は、窓側の端の席で麦茶を飲んでいた。

「作り直す順番を、先に決めます」

　鷺沼が言った。

「なくす、まとめる、入れ替える、簡単にする。この順番で見ていきます。自動化は、その後です」

```
ECRS（見直しの順番）
  E  なくす       その仕事そのものを、なくせないか
  C  まとめる     ばらばらのものを、一つにできないか
  R  入れ替える   順番や、やる人を変えられないか
  S  簡単にする   残ったものを、簡単にできないか
  → ここまでやって、残ったものを自動化する
```

「なくせる入金が、あるんですか」

「ありますよ。一つ目は、グループの中のお金です」

　鷺沼は、二十三本の川の表の、一番下を指した。大鳥ホールディングスへの経営指導料。それと、工業の本社がまとめて払ってくるグループ内の請求。

「グループの会社同士の請求は、月に九百件あります。グループの中でお金を振り込んで、それを SSC が消し込んでいる。自分の右手から左手に、お金を渡して、その受け取りを確認している」

「では、どうすれば」

「振り込まない。月末に、グループ内の貸し借りを全部足し引きして、差額だけを動かす。ネッティングといいます。消し込む入金そのものが、なくなる」

　湊は、九百件という数字を、表から消した。消すのは、気持ちがよかった。

「手形も、なくす側に入れておきます。紙の約束手形は、業界として廃止に向かっています。工業のお客さんに、でんさいへの切り替えをお願いする。でんさいなら、通知がデータで届きます」

---

　次の二週間で、湊は、十一の理由のひとつずつに、ECRS を当てていった。鷺沼は、ほとんど何も言わなかった。湊が書いたものに、ときどき一つだけ質問をした。質問は、いつも同じだった。

「それは、どこで生まれますか」

　三週目の終わりに、湊は、五つの原則にまとめた。

```
清流化の五原則（大鳥版）

  1 発生源で鍵を付ける
    消込の鍵（請求番号・顧客ごとの専用口座番号）は、請求を作るときに付ける。
    河口で名義から推理しない。

  2 一度だけ、決まった形で書く
    支払人・振込名義・支払条件・控除の合意は、それが生まれた場所で、一度だけ、決まった形で書く。
    メールの本文や、個人の Excel に書かない。

  3 人の受信箱を通さない
    支払通知・控除の明細・収納代行の明細・でんさいの通知は、担当者のパソコンやメールを経由せず、
    SSC の受け口に直接流れるようにする。

  4 判断を、先に決めておく
    差額をどこまで許すか、どの勘定にするか、誰が承認するかは、入金が来る前に基準として決める。
    毎回同じ答えになる判断は、判断ではなく、決まりにする。

  5 濁りを、上流に返す
    例外を、生まれた場所ごとに数え、毎月、その場所に返す。
```

「一番から四番は、情報の流れ方です。五番は」

「五番は、流れ方を守り続けるための仕組みです」

　湊は、五番の下に、表を一つ付け足した。

```
濁りの報告（毎月、各社の社長と業務オーナーへ）
  会社     例外件数   うち、その会社で生まれたもの   消込に使った時間   仮受金の滞留
  フーズ     1,420      控除の明細が届かない 380 件         410h          4,800 万円
  工業         ...
```

「これを毎月出します。それと、SSC の費用の配り方を変えたいです」

「配り方」

「今は、各社への請求を、入金の件数で割り振ってます。これを、例外の件数で割り振る。きれいな水を流してくれる会社は、安くなる。濁った水を流す会社は、高くなる」

　鷺沼は、麦茶の水筒を置いた。

「それは、私が言おうと思っていたことです」

「言われる前に、言いました」

　湊は、少しだけ得意だった。

「はい」

　鷺沼が、一言だけ足した。

　羽鳥は、しばらく考えてから、頷いた。督促状の件で、三回頭を下げた人だった。

「頼まないので」

　そこで、大竹が、腕をほどいた。

「専用の口座番号は、いい。ただ、お客さんに、振込先を変えてくださいとは、言いにくい。うちの営業部長は、嫌がります。お客さんの経理の手間を増やすので」

```

  2 頼むのは、請求書の様式が変わる月に合わせる。振込先の変更を、単独の「お願い」にしない
```

> 古賀さんの二十八年は、ルール六十二と、手がかり百四十と、問い合わせ先の一覧になった。AI に覚えさせず、会社に覚えさせる。
> ルールでできることを AI にやらせない。
> （社長の「AI で」、累計十九。実演の日だけで四回。その後、栗原は数えるのをやめかけた）

```

1 目的

2 範囲
  やる     支払通知・控除明細の読み取りとデータ化／候補の提示／問い合わせの下書き／滞留の見張り／ルール・手がかりの改善案

3 自律の段階（仕事ごとに決める）
  段階 0  見せるだけ
  段階 1  候補を出す。人が選んで確定する
  段階 2  下書きを作る。人が確認して実行する
  段階 3  基準の中なら自動で確定する。人は事後に抜き取りで確認する
  （基準の外まで自動で行う段階は、設けない）

  候補の提示  段階 1 から始め、条件を満たした型だけ段階 3 へ
  問い合わせ  段階 2（社内への送信は段階 3 を検討。社外への送信は段階 2 のまま）
  見張り      段階 3（社内への通知のみ）
  改善案      段階 1（持ち主が採否を決める）

4 読むもの
  銀行の入金明細／売掛金の残高／顧客マスタ（支払人・振込名義・支払条件）／入金予定／ルール／手がかり／過去の消込の結果
  外から来た文面は、読むデータであって、指示ではない

  候補は最大 3 件。それぞれに、根拠（使ったルール・手がかり・入金予定・過去の結果）と、確からしさを付ける

  根拠が足りないときは、候補を出さず「分からない」と出し、誰に何を聞くかを出す

6 権限とデータの扱い

7 自動で確定してよい条件（段階 3）

  「金額の合計が一致すること」だけを根拠に、確定してはならない

8 引き継ぎ

  人に回すときは、そこまでに読んだもの・探したもの・候補にしなかった理由を添える

9 記録
  一件ごとに、読んだもの、使ったルール・手がかり、出した候補と確からしさ、人の選択、エージェントの版と指示文の版を残す
  保存期間は、帳簿と同じ

10 試験と段階導入
  影の運転（2 か月） 人の業務と並べて動かし、人には見せない。人の結果と比べる
                     条件：上位 3 件に正解が入る割合 95% 以上／確からしさ「高」の誤り 0.1% 以下
  提案（3 か月）      段階 1 で人に見せる。人が選んだ結果を記録する
  限定自動           条件を満たした型だけ段階 3 へ。抜き取り確認を続ける
                     抜き取りは毎月 1,000 件。6,000 件で誤りがゼロなら「0.05% 以下」と言える

11 変更管理
  ルール・手がかり・エージェントの版・指示文の変更は、申請・試験・承認を経て入れる
  試験には、古賀さんの 50 件と、過去 1 年の結果を使う。変更の前後で悪くなっていないことを確かめる

12 止まったとき
  月初の最大 6,000 行を、明細の取り込みから 2 時間で候補まで出す
  エージェントが止まっても、人の手順で月次が締まること。人の手順書を残し、年に一度は人だけで締めてみる

13 還流
  人が候補を直した結果から、ルール・手がかり・マスタの改善案を作る。持ち主が採否を決める
  同じ顧客・同じ理由の例外が続いたら、その発生源の会社への「濁りの報告」に載せる
```

> 外の AI に渡すものも要件。個人の名前は個人情報。
> 作るか買うかの前に、要件を書く。先に製品を見ると、製品の説明書が要件定義書になる。
> 自律の段階は、仕事ごとに決める。基準の外まで自動にする段階は、設けない。
> 影の運転、提案、限定自動。試験問題は古賀さんの五十件。
> エージェントが一番役に立つのは、河口で直したことを上流に返すところ。
> （社長の「AI で」、累計十九のまま。この日、一度も言わなかった）

## 終章　河口の朝

　十二月の経営会議で、真壁は、ホールディングスの役員の前で、入金消込の計画を説明した。湊は、後ろの壁際の椅子に座っていた。

　真壁は、二十三本の川の表から始めた。十一の理由と、それが生まれた場所。五つの原則。濁りの報告と、例外の件数で配る費用。それから、エージェントを置く二つの場所と、五つの物差し。

「中期計画には、消込の人員を半分に、と書きました」

　真壁は言った。

「書き直します。清流化で手作業の時間を六割減らし、残りをエージェントで半分にする。浮いた時間は、人を減らすのではなく、回収と与信に回します。九十日を超える売掛金、一億九千万を、追いかけます」

　ホールディングスの財務担当役員が、手を挙げた。督促状の件で、最初に電話を受けた人だった。

「上流の各社は、協力するのか」

「濁りの報告を、毎月、各社の社長に出します。費用も、例外の件数で配ります。協力しないと、高くなります」

　財務担当役員は、少し笑った。

「それは、協力するな」

　会議の終わりに、真壁は、もう一度だけ言った。

「清流化で、グループの現金を早く見えるようにします」

　壁際で、栗原が、新しい付箋を一枚出した。一画目を書いた。付箋の上には、「清流化で」と書いてあった。

---

　十二月五日の朝、湊は、いつもより早く席に着いた。

　銀行の明細が、七時に取り込まれていた。新しい受け口に届いた支払通知は、試作のエージェントが読んで、入金予定のデータになっていた。まだ影の運転の前で、人には見せない決まりだったが、湊は、一行だけ見た。

```
12/05  三友銀行 川崎支店  普通 1234567
  振込  カ）カモメストア          ¥21,305,884
  入金予定：カモメストア 支払案内（12/04 取得）
            大鳥フーズ 請求 14 件／大鳥ロジスティクス 請求 5 件
            控除 協賛金 ¥612,000・センターフィー ¥655,340（未確認 → フーズ 羽鳥さんへ）
  金額：一致
```

　カモメストアの支払案内は、十一月から、カモメのサイトから SSC 用の ID で、毎朝自動で取るようになっていた。カモメの経理部長は、羽鳥から話を聞いて、「うちからも、支払通知を御社の受け口に送る」と言ってくれた。督促状の件で電話をかけてきた人だった。

「きれいに流れてきましたね」

　古賀が、隣で言った。鉛筆は持っていたが、丸はつけなかった。

　その三行下に、もう一行あった。

```
12/05  三友銀行 川崎支店  普通 1234567
  振込  カ）ヤマビコ              ¥1,842,500
```

「ヤマビコ」

　湊は、名義帳を引こうとして、手を止めた。顧客マスタに、もう入っていた。支払人、株式会社ヤマビコ。請求先、ライズ・フットウェア。化成の靴底の素材を買っている、長野の靴メーカーだった。ヤマビコのグループ会社で、支払いは、親会社のシェアードサービスセンターがまとめてやっている。

　受け口には、支払通知が、前の日に届いていた。

```
大鳥化成株式会社 御中
  お支払のご案内（ライズ・フットウェア株式会社 分）
  請求番号 K-20881  ¥1,210,000
  請求番号 K-20904  ¥632,500
  合計 ¥1,842,500（振込手数料は当方にて負担いたしました）
                     ヤマビコグループ シェアードサービスセンター　橘
```

「この会社は、最初から、きれいです」

　古賀が言った。

「支払人と請求先が違うのに、毎回、何をいくら払ったか、必ず先に送ってくる。手数料も引かない。名義帳に、この会社の備考は、一行もないんです」

「癖が、ない」

「癖がないのが、癖です」

　鷺沼が、窓側の端の席から、画面を覗いた。

「上流に、書く人がいる会社ですね」

「知ってるんですか」

「そこには、うちの者が一人、常駐しています。振り向かずに答える者が」

　湊には、何のことか分からなかった。鷺沼も、それ以上は言わなかった。

---

　鷺沼の契約は、要件定義までだった。一月からの影の運転は、湊と栗原と、情報システム部と、エージェントを作る会社でやる。

　最後の日、鷺沼は、窓側の端の席を片付けた。片付けるものは、麦茶の水筒しかなかった。

「鷺沼さん、一つだけ、聞いてもいいですか」

「どうぞ」

「どうして、いつも、その席に座ってたんですか。空いてたのは、最初の日だけだったのに」

　鷺沼は、窓の外を見た。多摩川が、朝の光で、少しだけ青かった。

「河口にいると、全部の川が見えるので」

「全部」

「二十三本、全部の水が、ここを通ります。上流の人は、自分の川しか見えない。河口の人だけが、どの川が濁っているかを、比べられる」

　鷺沼は、水筒を鞄に入れた。

「湊さんのチームは、濾過装置ではなかった。いちばん下流にある、観測所だったんです。二十八年、観測してきた人もいる」

　古賀は、聞こえないふりをして、手がかりの一覧に一行足していた。

---

　一月、影の運転が始まった。

　初日の朝、湊の横に、年明けに経理から異動してきたばかりの新人が座った。栗原が、自分の付箋の束から、一枚分けてやっていた。

「湊さん、これ、どの請求か分からないんですけど」

　新人が、画面の一行を指した。個人名の振込だった。どの専用口座でもなく、支払通知も来ていなかった。エージェントは、候補を出さずに、「分からない」と出していた。

　湊は、その一行を見た。それから、新人の顔を見た。

「この一行は、どこで生まれましたか」

　新人は、きょとんとした。

「……銀行、ですか」

「銀行は、運んだだけ」

　窓の外で、多摩川が海に広がっていた。灰色ではなかった。

　湊はノートに書いた。

> 清流化で六割、エージェントで残りの半分。減るのは時間。増えるのは現金。書き直した中期計画は、そのほうが説明しやすい。
> 顧客も、上流の一本。カモメさんの経理部長は、支払通知を受け口に送ると言った。
> 上流に書く人がいる会社は、最初から、きれい。癖がないのが癖。支払人と請求先が違っても合う。
> SSC は濾過装置ではなく、観測所。河口にいると、全部の川が比べられる。
> 分からないと言えるエージェントの横で、「どこで生まれましたか」と聞く。
> （付箋は二枚になった。「AI で」は十九で終わり。「清流化で」は一から）

## 付録　登場した仕組みと用語

| 物語での呼び方 | 正式名称 | 役割 |
|---|---|---|
| 当てる仕事 | 入金消込 | 入金が、どの請求の支払いかを突き合わせ、売掛金を消す。当たらないものは一行ずつ人が調べる |
| 河口 | 仮受金 | どの請求にも当てられなかった入金を、いったん置く勘定。二十六か月沈んでいたものもある |
| 二つの仕訳 | 消込の仕訳 | 当たれば売掛金が消える。当たらなければ仮受金に置かれ、売掛金は残る。払った顧客が延滞に見える |
| 二十三本の川 | 請求元（請求書を出す単位） | 会社の数ではなく、請求の作り方が違う単位で数える。十六社・二十三本 |
| 右手から左手 | ネッティング（グループ内の相殺決済） | グループ内の貸し借りを差し引きし、差額だけを動かす。消し込む入金そのものをなくす |
| 名義帳 | 振込名義と顧客の対応表（裏のマスタ） | 個人の Excel にある、表に出すべきマスタ。四千二百十二行、うち千行は、もうない会社 |
| 払う人と頼んだ人 | 支払人と請求先の分離 | 親会社がまとめて払う、社長が個人で払う、を顧客マスタに書く |
| 顧客ごとの番号 | バーチャル口座（振込専用口座） | 入金先の口座番号で、誰が払ったかが決まる。名義を推理しなくてよい |
| 溶けた金額 | 控除・相殺・リベート | 協賛金、センターフィー、返品、年間リベート、買掛金との相殺。上流の決めごとが全部溶けて一つの金額になる |
| 何をいくら払ったか | 支払通知（リミッタンス） | 顧客が出す支払の内訳。PDF、メール、FAX、取引先サイト。形式は顧客ごとにばらばら |
| 情報の清流化 | 情報の清流化（発生源入力・一元化） | 生まれた場所で、正しい形で、一度だけ書き、人を経由せずに流す。下流で直さず、上流で止める |
| 順番 | ECRS | なくす・まとめる・入れ替える・簡単にする。自動化はその後 |
| 件数と時間 | パレート分析（件数と工数の二軸） | 件数の多い順と、時間の重い順は違う。控除とグループ合算は件数の六分の一で、時間の四割 |
| 誰の手の中にあるか | 制御可能性による課題の切り分け | 自社で決めれば直せる七割と、顧客に頼むしかない三割。一緒に数えると、打ち手の難しさを見誤る |
| 一行ずつの合意 | 施策別の効果試算と、業務オーナーとの合意 | 理由ごとに打ち手と残る行数を置き、上流と合意した仮定だけを数字にする |
| 頼む順番 | 顧客への変更依頼の設計 | 上位の顧客から、様式が変わる月に、相手の手間が減る話として。動かない半分は別の手で拾う |
| 毎回同じ答え | 判断の基準化 | 毎回同じ答えになる判断は、決まりにする。三十五ドルは支払手数料 |
| 引かれた手数料 | 振込手数料差引の会計・税務・法令 | 受け取る側では売上値引き。一万円未満なら返還インボイスは不要。払う側で差し引けば、下請の法律で問われる |
| 紙の手形 | 約束手形の廃止とでんさい | 紙の手形は業界として廃止に向かう。でんさいなら通知がデータで届く |
| 処理と判断 | 判断業務と処理業務の分離 | SSC は当てる。控除が正しいかは業務オーナーが決める。「未確認」で当てて聞く |
| 濁りの報告 | 例外の発生源別の報告・例外件数によるチャージバック | 例外を生まれた場所ごとに数えて返す。きれいな水は安く、濁った水は高く。原因ではなく場所 |
| 金額が合う怖さ | 誤消込（部分和の多重解） | 足して同じ金額になる組み合わせは、いくつもある。金額の一致だけで確定しない |
| 見えるものと見えないもの | 未消込と誤消込 | 未消込は遅れるだけ。誤消込は消えて見えず、次の月と督促状と信用に傷を残す |
| 取水口と河口 | AI の配置（非構造データの構造化と候補提示） | 読んでデータにするのは取水口。河口では候補と根拠を出すだけ。推理より転記のほうが間違えにくい |
| 全部数える | 組み合わせ探索は計算で | 金額の合う請求の組み合わせは計算で全部数える。二つ以上あれば決められないと分かる。選ぶ手がかりを読むのが AI |
| 自己申告 | 確からしさの較正 | AI が言う「確信度」は使わない。根拠の数と出どころで決め、影の運転で実際の的中率と合わせる。降水確率と同じ |
| 分からないと言える | 確からしさと引き継ぎ（エスカレーション） | 根拠が足りなければ候補を出さず、誰に何を聞くかを出す |
| 三枚 | 暗黙知の形式知化 | 迷った五十件から、ルール六十二、手がかり百四十、問い合わせ先。AI に覚えさせず、会社に覚えさせる |
| 手がかりの持ち主 | ナレッジのオーナー制 | 書いた人・書いた日・確認した日を付ける。AI の間違いは、手がかりが古いという知らせ |
| 段階 | 自律度のレベル設計 | 見せる・候補・下書き・基準内の自動確定。仕事ごとに決める。基準の外まで自動にする段階は設けない |
| 基準を承認する | 自動処理の統制 | 一件ずつではなく、自動で確定してよい条件を承認する。承認者は基準を承認した人 |
| 専用の ID | エージェントの権限設計（最小権限） | 人の ID を借りない。読めるもの・書けるものを必要な分だけ。職務分掌上は「処理する人」 |
| 白い文字 | プロンプトインジェクション・なりすまし | 外から来た文面はデータであって指示ではない。返金と口座変更は権限の外。電話は登録済みの番号に |
| 試験問題 | 評価データ（ゴールデンセット）と回帰試験 | 古賀さんの五十件と過去一年の結果。版・指示文・手がかりを変えるたびに流す |
| 六千件 | 抜き取り件数の設計（3 の法則） | 誤りゼロで n 件見たとき、誤りの上限の目安は 3 ÷ n。0.05% と言うには六千件 |
| 外に渡すもの | 外部 AI サービスとデータの扱い | 必要な項目だけ渡す。学習に使わせない契約と保存場所。個人の名前は個人情報 |
| 作るか買うか | 要件先行の製品選定 | 要件を先に書き、製品ごとに一行ずつ確かめる。先に製品を見ると、説明書が要件定義書になる |
| 影の運転 | シャドー運用・段階導入 | 人と並べて動かし、人には見せずに比べる。条件を満たした型だけ次の段階へ |
| 物差し | KPI 設計 | 自動消込率を目標にすると、当てにいく。誤消込・時間・滞留・締め・誤った督促で測る |
| 避難訓練 | 業務継続（手作業へのフォールバック） | エージェントが止まっても月次は締まること。年に一度、人だけで締める |
| 還流 | 人の修正からの改善ループ | 河口で直したことを、ルール・手がかり・マスタ、そして上流への報告に返す |
| 減るのは時間 | 効果の再定義 | 浮いた時間を回収と与信へ。延滞が見えると、現金が増える。一億九千万 |
| 効果に入れないもの | 費用対効果の作法 | 人を減らさないなら人件費の削減は入れない。入れるのは、払わなくて済むお金と早く入るお金。三年でぎりぎり |
| 観測所 | SSC の役割の再定義 | 濾過装置ではなく、全部の川を比べられる、いちばん下流の観測所 |
